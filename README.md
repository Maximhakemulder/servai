# SERVAI

Landingspagina voor **SERVAI · AI for hospitality**: het AI-platform dat kassa, reserveringen, rooster, inkoop en reviews koppelt voor de horeca.

## Structuur

- `index.html`: de complete landingspagina (HTML, CSS en JS in één bestand, logo's ingebed)
- `assets/`: logo's (wit, transparant), merkbeeld met gradient en favicon

## Live zetten

Statische site, geen build nodig. Koppel deze repo aan Netlify, Vercel of GitHub Pages en wijs `servai.nl` naar die host.

## Nog te doen

- Demo-formulier koppelen aan een echte ontvanger (bijvoorbeeld Netlify Forms, Formspree of een CRM)
- Voorbeeldcijfers in de demo's vervangen door echte cases zodra die er zijn
- Privacyverklaring en cookiemelding toevoegen
